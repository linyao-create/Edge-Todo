# Edge Todo

Edge Todo 是 Mac 屏幕边缘的待办和随记面板。打开后，把鼠标移到屏幕左侧的小条，就可以记待办或随记。

从 GitHub 下载项目后，把这个项目交给你的 AI，说：

> 帮我配置这个项目。

AI 会先问你要在 Edge、Chrome 还是两个浏览器中安装收藏扩展，然后准备本机数据文件夹，协助连接你自己的飞书。飞书需要登录或授权时，按 AI 的提示操作。完成后，AI 会告诉你数据保存在哪里。

你也可以让 AI 先帮你完成本地使用，之后再连接飞书。

## 数据保存在哪里

请先让 AI 完成配置，再打开应用。按上面的方式配置时，AI 默认在项目文件夹旁准备「EdgeTodo数据」文件夹，并在完成后告诉你实际位置。待办、随记和网页链接保存在里面的 `todos.json`，倒计时保存在 `countdowns.json`。

如果没有经过 AI 配置就直接打开 Mac 安装包里的应用，应用会使用 `~/Library/Application Support/EdgeTodo/`。如果你以前用过 Edge Todo，这个位置可能已经有旧数据，直接打开可能读取或改动旧记录。因此已有旧版时，请不要直接打开未配置的应用；先让 AI 为新版选择独立的数据文件夹。已有文件不会自动迁移；如果你希望使用旧记录，先让 AI 和你确认数据位置及备份，再决定如何处理。

面向 AI 的完整步骤见项目根目录的 AGENTS.md。
