把当前网页存到随记

把 Edge Todo 图标固定在地址栏右侧，和收藏星标放在同一区域。以后点击图标，当前网页的标题和完整链接就会进入 Mac 的随记。

  1. 先安装并打开支持浏览器接收功能的 Mac 版 EdgeTodo.app。
  2. 打开 Edge 的 edge://extensions，开启「开发人员模式」。
  3. 点击「加载解压缩的扩展」，选择此项目的 browser/extension 文件夹。
  4. 在地址栏右侧的扩展菜单中，找到「Edge Todo：存当前页到随记」，选择「在工具栏中显示」。
  5. 打开普通网页，单击蓝色随记图标。

图标显示在地址栏右侧的扩展工具栏，不能放进 Edge 原生收藏星标所在的地址栏内部。首次使用时，Edge 可能询问是否打开 Edge Todo；请确认。保存成功后，Mac 随记面板会显示新条目。

只保存页面标题和完整链接，不收录图片、视频或全文。edge://、新标签页和本地文件等页面不能保存；图标上的感叹号表示扩展无法发起请求，可将鼠标移到图标上查看原因。

备用：使用收藏夹栏按钮

不安装扩展时，也可以把下方按钮拖到 Edge 收藏夹栏；按 Command + Shift + B 可显示收藏夹栏。旧按钮仍可使用。

存当前页到随记

还可以新建收藏夹，名称填「存当前页到随记」，网址粘贴下方内容；或在收藏夹管理页导入同目录的 edge-favorites.html。
